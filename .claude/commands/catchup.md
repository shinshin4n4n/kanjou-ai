## コンテキスト再構築コマンド

`/clear` 後やセッション再開時に、作業コンテキストを効率的に再構築します。

### ワークフロー

1. **保存済み作業状態の読み込み**
   - `.claude/last-session-state.md` が存在すれば Read で読み込む（PreCompact フックが生成）
   - 存在しない場合はスキップ

2. **現在のブランチ状態を確認**
   ```bash
   git branch --show-current
   git status --short
   git log --oneline -5
   ```

3. **main からの変更差分を取得**
   ```bash
   git diff --name-only main
   git diff --stat main
   ```

4. **変更されたファイルの内容を確認**
   - 変更ファイルを Read で読み込み、変更内容を理解する
   - テストファイルがあれば TDD フェーズを推定

5. **作業状態レポートを生成**
   以下の構造で報告:

   ```
   ## 作業状態レポート

   **ブランチ:** {branch_name}
   **関連 Issue:** {issue_number（ブランチ名から推定）}

   ### 完了済み
   - （変更内容から推定）

   ### 進行中
   - （未コミットの変更から推定）

   ### 残作業
   - （Issue の要件と現在の変更を比較して推定）

   ### TDD フェーズ
   - 現在のフェーズ: RED / GREEN / REFACTOR（テストの状態から推定）
   ```

6. **次のアクションを提案**
   - 残作業がある場合: 次に着手すべきタスクを提案
   - 全完了の場合: PR 作成を提案
